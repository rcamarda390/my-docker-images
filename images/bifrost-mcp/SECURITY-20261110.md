redirect fix commit `c7fb7bb8b83c55c63c21a298349d4c2c12833d31` is already
an ancestor of `v0.69.0`. Preserve the Xray row for scanner reconciliation.

asserts the resolved module graph and the versions in `/app/main` build
metadata. The existing MCP request-body regression, setup-token smoke
test, and health checks remain enabled. The existing workflow selects
the next immutable tag after merge.

checked-in image recipes contain no explicit consumers of these paths.

evidence before assigning applicability. The Debian tracker recheck
returned 35 open, 2 resolved, and 56 upstream-review entries. The
