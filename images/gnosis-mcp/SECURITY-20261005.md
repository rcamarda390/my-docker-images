## Gnosis dependency research

- gnosis-mcp 0.17.5 (PyPI) is pure Python; native needs come from onnxruntime (libstdc++/libgcc_s/libc), tokenizers (libc/libgcc_s), sqlite-vec, numpy. No GCC package is used directly.
- No runtime path invokes gcc, tar, or system utilities (see SECURITY-20261002.md).

## Remaining

libc6, libgcc-s1, libstdc++6, dash, tokenizers rows stay in Xray; no further package is removable without breaking the runtime. Real GCC runtime rebuild (Debian `DEB_STAGE=rtlibs`) is not justified given non-applicability above.
