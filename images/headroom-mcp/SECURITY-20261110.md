# Headroom 0.44.0 Wolfi baseline Xray remediation

The November 10 CSV reports 24 component rows across 12 advisories for
`0.44.0-wolfi-v1`. The CSV gives no image-level digest. Its two physical
layer digests match the public manifest
`sha256:e358fd8f3089df353285ff1680be3966b6f429479e151542f31112a9bf2cea46`.
The original report rows and scanner fields are preserved in the
[shared ledger](../../docs/security/findings.json).

The next immutable revision enables remediation mode. It retains the
Bedrock/Cline compatibility patch, the LiteLLM functionality pin, and
the baked Kompress model.

## Sibling review

- AgentMemory, Bifrost, Gnosis, AI CLI runner and GitHub MCP Server already
  set the three Wolfi package floors in their runtime recipes. AgentMemory's
  npm Transformers library has a different package identity from the Python
  Transformers report. Its other compiled copies still need inventory evidence.
- Gnosis already locks Pydantic `2.14.2` with core `2.50.2`. Its current
  Tokenizers `0.23.3` lock remains a source-level follow-up because the wheel
  still fails the regression. Gnosis needs a separately validated hash-locked
  wheel and offline startup test.
- LiteLLM already enforces the glibc floor. Its zlib, certificate bundle, and
  resolved Python package versions need exact-artifact evidence. GitLab MCP
  enforces the certificate bundle floor, with its glibc and zlib state pending
  exact-artifact evidence.
- Alpine eBay, Docker Socket Proxy and Sooperset Atlassian, and UBI Zeus use
  separate vendor packages. Scratch SQZ and slim payloads have no Wolfi package
  database. Embedded or statically linked equivalents remain unverified unless
  explicitly recorded above. The separate Debian recipes retain their own
  treatments.

The build runs the BPE and checkpoint-shard regressions against the final
Wolfi runtime and asserts the APK and Python versions. It also runs the
existing Bedrock compatibility regression and container smoke test.

Use the new image digest for an Artifactory Xray rescan. Xray may still flag
the package version when a downstream source patch provides the fix.
