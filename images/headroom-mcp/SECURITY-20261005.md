# Headroom: 2026-10-05 Xray remediation

Scope: 137 supplied component/advisory rows, including 58 distinct CVEs and
six rows without a CVE ID. The report omits installed versions and the scanned
image tag. The candidate uses the current Headroom 0.39.1 source, commit
`d13e1966f820220b482a33c30bde1e926743939a`, and starts at revision floor 2.
Publication chooses the next unused revision; a candidate build does not publish.

## Approach

Prefer fixed same-suite packages and compatible upstream dependency releases.
Check source and Debian applicability before treating a version suffix as proof.
Remove components only after tracing Headroom usage, querying installed reverse
dependencies and checking native links. Keep required libraries. Existing Gnosis
backports against the identical Debian source are reused rather than rewritten.
No findings are suppressed and package metadata remains in the final image.

## Unused util-linux family

Remove `util-linux`, `mount`, `bsdutils`, `libmount1`, `libblkid1`,
`libsmartcols1` and `libuuid1`: 42 supplied package/advisory rows.
Headroom 0.39.1 Python/Rust source, entrypoint and smoke scripts do not invoke
their namespace, mount, block-device, scheduling, logging or UUID commands.
Its locking calls use `fcntl.flock`, not the `flock` executable. UUID values
use Python; the optional `_uuid` extension is removed to select the supported
Python fallback, and UUID1/UUID4 generation is exercised afterward.

`verify-runtime-unused.py` queries installed Depends and Pre-Depends,
including alternatives/multiarch names, before the purge. It fails if any
retained Debian package names a removed package. It checks the actual Python,
Dash and every ELF shared object under /usr/local and /opt/venv with ldd,
failing if a native closure needs any removed library. ldd errors fail closed.
Final checks require package, command and library absence. Existing proxy,
dashboard and offline compression smoke tests must still pass.

This covers the source-family associations for CVE-2026-78408,
CVE-2026-78410, CVE-2026-76642, CVE-2026-78409, CVE-2026-3184 and
CVE-2022-0563. The first five have newer-suite fixes, but retaining an unused
tool suite from Sid would add unnecessary ABI and packaging risk.

and UTF-8 boundary cases), a valid BPE merge, rejected traversal/absolute/symlink
checkpoint paths and a valid nested checkpoint. Existing Bedrock tests cover
streaming/non-streaming parameter handling and native system cache markers.
Final checks repeat security tests after the runtime purge and assert fixed
Debian floors. The existing workflow builds, runs its proxy/compression smoke
test and performs an advisory Trivy scan. A new Xray scan of the exact rebuilt
immutable tag is required before declaring the supplied findings cleared.
