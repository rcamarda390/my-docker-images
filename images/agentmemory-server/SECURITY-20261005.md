## Plan critique

Check Debian and upstream code before deciding whether a package-version finding
needs an update. Prefer a fixed same-suite source, then remove only components
with proven absence of supported runtime use and reverse/shared dependencies.
Backport or replace required components only with compatible, verifiable code.
A +rcamardaN suffix identifies a downstream build, not its security status.
Changing that suffix alone cannot fix code or clear an unfixed-suite advisory.
The supplied report omits installed versions, image digest and the anonymous
SDK advisory identifiers; compare a new Xray scan against the exact candidate.
